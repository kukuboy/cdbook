# 易错点

## js storage存储变成[object,object]

__问题：__ 在把对象存入localstorge或sessionstorge时，再直接拿出时可能会变成[object object]  
__解决方法：__ 存入时用JSON.stringify转化，取出时再用JSON.parse转化回来即可

## fill 之后数组的内容一变都变
__问题：__ 比如在fill之中再放入一个数组，数组中某一个项改变时，其他的也会跟着改变
__解决方法：__ fill填充的是对这个对象的引用，故最好不要在fill中填入引入类型
````javascript
let arr = new Array(3).fill(new Array(3).fill(false))
arr[0][0]=true
console.log(arr)
    输出：
    [
        [true,false,false],
        [true,false,false],
        [true,false,false]
    ]
````
## es6数组的方便遍历方法

    for (let index of ['a', 'b'].keys()) {
    console.log(index);
    }
    // 0
    // 1

    for (let elem of ['a', 'b'].values()) {
    console.log(elem);
    }
    // 'a'
    // 'b'

    for (let [index, elem] of ['a', 'b'].entries()) {
    console.log(index, elem);
    }
    // 0 "a"
    // 1 "b"

如果不使用for...of循环，可以手动调用遍历器对象的next方法，进行遍历。


    let letter = ['a', 'b', 'c'];
    let entries = letter.entries();
    console.log(entries.next().value); // [0, 'a']
    console.log(entries.next().value); // [1, 'b']
    console.log(entries.next().value); // [2, 'c']

# 对象和继承

````javascript
// js常见的对象
function Person(name="张三"){
  this.name=name
  this.run=function (){
    console.log(`${this.name}在跑步`)
  }
}
Person.prototype.work=function (){
  console.log(`${this.name}在工作`)
}
// 对象冒充继承
function newPerson(){
  Person.call(this)
}
// 原型链继承
function newAgainPerson(name){
  Person.call(this,name) //加对象冒充方法可以传入参数
}
// newAgainPerson.prototype=new Person()
newAgainPerson.prototype=Person.prototype //防止重复继承
let n = newPerson()
n.run()
// n.work() 不可以继承原型链上的，此无法运行
let nn = newAgainPerson()
nn.work() // 可以运行
````
